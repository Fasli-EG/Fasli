# فَصلي — بناء ونشر تلقائي مجاني بالكامل (سطح مكتب + موبايل)

## الفكرة
دفعة واحدة (`git push` بتاج جديد) → GitHub يبني نسخة Windows و Mac و Android تلقائياً → 
كلهم بينشروا كـ "Release" برابط تحميل **ثابت** تحطه في إعدادات النظام مرة واحدة، ومايتغيّرش تاني حتى لو حدّثت النسخة (لو استخدمت `/latest/`).

---

## الإعداد (مرة واحدة بس)

### 1) غيّر رابط موقعك
في **الملفين** دول:
- `electron/main.js`
- `mobile/capacitor.config.json`

غيّر `https://your-fasli-domain.com/login.html` لرابط موقعك الحقيقي (لازم HTTPS).

### 2) ارفع المجلد ده كله على GitHub
اعمل repo جديد (خاص أو عام، الاتنين مجانين) وارفع المجلد بالكامل بنفس الهيكل ده:
```
├── electron/
├── mobile/
└── .github/workflows/
```

### 3) فعّل صلاحية الكتابة للـ workflows
في الـ repo: Settings → Actions → General → Workflow permissions → اختار "Read and write permissions" واحفظ.
(الخطوة دي مطلوبة مرة واحدة بس عشان الـ workflow يقدر ينشئ Release تلقائي)

---

## الاستخدام (كل مرة عايز تنشر نسخة جديدة)

```bash
git tag v1.0.0
git push origin v1.0.0
```

بس كده. روح تبويب **Actions** في الـ repo، وهتلاقي 3 عمليات بناء شغّالة بالتوازي (Windows, Mac, Android) — كل واحدة بتاخد من 3 لـ8 دقايق تقريباً.

لما يخلصوا، روح تبويب **Releases** في الـ repo، وهتلاقي:
- `فَصلي-Setup.exe` (ويندوز)
- `فَصلي.dmg` (ماك)
- `فصلي.apk` (أندرويد)

## الروابط الثابتة اللي تحطها في إعدادات النظام
بدل ما تنسخ رابط كل ملف كل مرة (وده بيتغيّر كل إصدار)، استخدم رابط "أحدث إصدار" الثابت ده، وهو دايماً بيوجّه لآخر نسخة رفعتها:

```
رابط الكمبيوتر (ويندوز):
https://github.com/Fasli-EG/Fasli/releases/latest/download/فَصلي-Setup.exe

رابط الموبايل (أندرويد):
https://github.com/Fasli-EG/Fasli/releases/latest/download/فصلي.apk
```
الرابطين دول جاهزين فعلياً باسم حسابك (Fasli-EG) وريبو (Fasli) — بعد ما تعملي أول إصدار، حطيهم زي ما هما في صفحة "إدارة النظام → إعدادات النظام".

## ملاحظات مهمة
- **الـ APK ده "debug build"** — شغّال 100% للتحميل المباشر، بس لو عايز تنشره على Google Play لازم "release build" موقّع، وده خطوة إضافية مختلفة (موضّحة في `mobile/SETUP_STEPS.md` من الحزمة اللي فاتت).
- **مفيش أي تكلفة في الخطوات دي كلها** — GitHub Actions بيوفر وقت بناء مجاني كل شهر كافي جداً لاستخدام زي ده.
- لو عايز تحدّث النسخة تاني، كرّر نفس الخطوة بتاج جديد (`v1.0.1` مثلاً) — الروابط الثابتة هتتحدث تلقائي.
